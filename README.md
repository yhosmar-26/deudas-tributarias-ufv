# DEUDAS TRIBUTARIAS

Dashboard interactivo con búsqueda exacta de UFV por fecha de vencimiento y fecha de pago. La base diaria está integrada en `index.html`; también puede descargarse desde `base_ufv_diaria.csv`.

## Cobertura de la base

- 9.135 cotizaciones únicas, desde 07-12-2001 hasta 10-12-2026.
- 2002–2025: cobertura diaria completa.
- 2001: la hoja contiene datos desde 07-12-2001.
- 2026: el archivo llega hasta 10-12-2026; no hay valores del 11 al 31 de diciembre.
- El dashboard busca por fecha exacta. No estima valores ausentes.

Las entradas del cálculo se procesan en el navegador y no se guardan en el sitio.
